# DESIGN — Bellam & Kaaram

**Direction:** "The Muggu Doorstep" · Mode: Persuade · seed `bb026b76` (candidate 7/7, code-led)

This is a from-scratch replacement of the incumbent cream / Playfair / soft-shadow
photo-card "authentic South Indian delivery" template. The old look is
anti-reference only.

## Thesis

The kitchen as the Telugu doorstep you pass every morning. The *muggu* (dawn
rice-flour threshold pattern) is the page's structural grid; its two poles are
**bellam** (jaggery-warm) and **kaaram** (chilli-hot); the ~90-dish regional
menu is navigable along that taste axis.

## World

| Token | Value | Role |
|---|---|---|
| `--earth` / kaavi ground | `#4a2f20` | one unbroken ground, top to bottom |
| `--chalk` | `#f4ede0` | rice-flour muggu dot-lattice, primary text |
| `--turmeric` / `--jaggery` | `#f4c150` / `#e0a92e` | **bellam** pole (sweet) |
| `--chilli` / `--marigold` | `#a5231b` / `#f26a2e` | **kaaram** pole (heat) |
| `--zomato` / `--swiggy` | `#c92030` / `#fc8019` | **only** on order buttons |

- **Type:** Darker Grotesque (display), Hanken Grotesk (body/roman), Gurajada +
  Noto Sans Telugu (Telugu). `--radius: 0`.
- **Texture:** newsprint tooth over the earth ground; a chalk radial-dot muggu
  lattice (34px) composited into `body`; rubber-stamp price/rating marks.
- **No photography** — none exists for this brand; the design is built to not need it.
- **Bilingual lockup:** `బెల్లం & కారం` set large, the `&` reading as the
  sweet↔spice axis (jaggery glow left, chilli red right); a roman descriptive
  line sits centered below.

## Structure

Two pages, hand-generated by `.impeccable/build.mjs` from
`.impeccable/menu-data.json` — no build step, committed `index.html` + `menu.html`.

- **index:** doorstep hero → sweet/spice axis explainer → 12 signature dishes →
  ledger of proof (89 dishes / delivery-only / ₹250 / hours) → kitchen + hours.
- **menu:** all 89 dishes across 13 categories, each tagged `BELLAM` / `KAARAM` /
  `HOUSE`, Telugu category labels, sticky order bar.
